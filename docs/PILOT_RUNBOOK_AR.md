# DTY ERP V0.6 — Pilot Runbook

## الهدف
تشغيل وردية واحدة على ماكينة تجريبية (`DTY-CN-02` افتراضيًا) ومقارنة النظام بالسجل اليدوي قبل تعميمه.

## قبل الوردية
1. تشغيل `/pilot` والوصول إلى Go = جاهز لكل الفحوص الحرجة.
2. جرد POY Lot فعلي ومطابقة الكمية والـQR.
3. التأكد من أمر إنتاج Released واحد فقط للـPilot SKU.
4. التأكد من المستخدم Operator والوردية الصحيحة.
5. تسجيل قراءة عداد الكهرباء أو طريقة توزيع kWh المعتمدة.

## أثناء الوردية
1. Start Production Run من شاشة العامل.
2. أي توقف يسجل Live START فورًا مع السبب.
3. عند عودة الماكينة، STOP Timer/استئناف فورًا.
4. لا تستخدم التوقف اليدوي إلا لتصحيح حدث موثق ومصرح به.

## نهاية الوردية
1. تسجيل Grade A / Grade B / Waste / kWh.
2. يجب نجاح Mass Balance.
3. إصدار Finished Lot تلقائيًا.
4. Quality Release/Hold حسب الاختبار.
5. تشغيل Actual Costing وOEE.

## المصالحة مع التسجيل اليدوي
يجب مقارنة:
- POY issued kg
- Grade A/B kg
- Waste kg
- Downtime minutes by reason
- Electricity kWh
- Yield
- OEE
- Full Cost/kg

## معايير نجاح أول Pilot
- فرق المخزون ≤ 0.2% أو سبب موثق.
- فرق الإنتاج ≤ 0.2% أو سبب موثق.
- كل توقف >5 دقائق موجود في ERP.
- Traceability كامل من POY Lot إلى DTY Lot.
- لا Finished Lot على Hold يمكن تخصيصه للبيع.
- لا خطأ حرج في صلاحيات المستخدم.

## بعد نجاح 3 ورديات
وسع الـPilot إلى ماكينة ثانية، ثم إلى 6 ماكينات فقط بعد تثبيت SOP الإدخال وتدريب المشرفين.
