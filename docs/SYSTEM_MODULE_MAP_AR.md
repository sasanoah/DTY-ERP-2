# خريطة DTY ERP V1.0-RC.2

`Master Data → Planning → MRP → RFQ → PO → Shipment/GRN → POY Lot/QC → Inventory → Production Order → Run/Shift → Downtime/OEE → DTY Lot/QC → FG → Quotation → SO/Credit → Allocation → Dispatch → Invoice → Collection`

المسارات المساندة:
- `Production/Machine → Maintenance → Spare Parts → Actual Maintenance Cost`.
- `POY Lot → Supplier Scorecard`.
- `DTY Lot → Cost Snapshot → Customer True Profitability`.
- `Transactions → Audit / Alerts / Approvals → Control Tower`.
- `ERP Read Models → Arabic AI Factory Assistant (Read-only)`.
